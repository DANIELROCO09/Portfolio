Project Overview

The objective of this project is to help beginners improve algorithmic reasoning and logical thinking through randomized exposure to introductory competitive programming problems.

Instead of manually searching across multiple platforms, the script automates the discovery process and provides quick access to beginner-oriented exercises such as Watermelon, basic math problems, implementation tasks, and introductory logic challenges.

Engineering Process

Situation

Beginner programmers often struggle to find appropriate problems for developing logical reasoning without becoming overwhelmed by advanced competitive programming content.

Task

Design a lightweight automation system capable of gathering randomized beginner-level problems from multiple online sources using a terminal-first workflow.

Action

Developed a shell-based script that fetches, filters, and organizes beginner-friendly algorithmic challenges while maintaining simplicity and minimal system overhead.

Result

Created a fast and practical learning utility for improving problem-solving consistency, logical thinking, and exposure to algorithmic patterns for novice programmers.

Technical Highlights

Shell Automation

Lightweight Bash-based workflow optimized for terminal environments.

Randomized Selection

Dynamic generation of random beginner-level exercises for consistent daily practice.

Problem Aggregation
